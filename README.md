# Welcome

## The Anzen Protocol: The Insurance Layer for the $100 Trillion Internet Financial System

Anzen is a programmable insurance and risk-management layer designed to make decentralized finance (DeFi) safe for everyone. Developed by RYG.Labs, the protocol acts as a "safety switch" for on-chain finance, transforming unpredictable risks into a manageable utility.

Instead of relying on static code audits that can't prevent every exploit, Anzen provides active, real-time protection for traders and investors. By leveraging the high-speed infrastructure of Circle’s Arc network, the protocol is able to offer immediate capital recovery. If a user suffers a qualifying loss—whether from a protocol failure, market manipulation, or an oracle dispute—Anzen settles the claim in milliseconds, moving funds back to the user's wallet instantly rather than making them wait months for a potential reimbursement.  

Anzen is specifically built to secure high-volume activities like perpetual futures trading and prediction markets, where speed and certainty are essential. By providing a reliable safety net, Anzen helps bridge the gap between traditional financial security and the efficiency of the blockchain, ensuring that the next generation of global finance is built on a foundation of guaranteed protection
