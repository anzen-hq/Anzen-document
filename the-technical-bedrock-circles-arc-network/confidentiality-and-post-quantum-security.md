# Confidentiality and Post-Quantum Security

Anzen integrates with Arc's privacy and security roadmaps to protect sensitive institutional data.

* **Opt-in Privacy Primitives:** Senders and amounts can be shielded by default using built-in privacy controls, while providing "view keys" to authorized auditors for compliance.
* **Quantum Resistance:** Arc is engineered with a roadmap for post-quantum signature support. At mainnet launch, it will introduce schemes for quantum-resistant wallets, protecting long-lived institutional assets from "harvest now, decrypt later" attacks.
