# Revenue & Payout Model

Upon insurance purchase, the smart contract immediately bifurcates the premium:

* 60% → Payout Pool: Strictly reserved for compensating user claims.
* 40% → Protocol Treasury: Allocated for revenue, system operations, and R\&D.

The Payout Pool represents the maximum liquid capital available for distribution at the end of each epoch. Any surplus remaining after all claims are settled is typically rolled into the Treasury.
